# P2 – Log phỏng vấn (ẩn danh)

> [ĐIỀN SAU KHI PHỎNG VẤN THẬT] File này là template. Không điền gì cho đến khi cuộc phỏng vấn thật đã diễn ra. Mọi dòng "Ví dụ cách ghi" chỉ minh họa định dạng, không phải dữ liệu, và phải xóa trước khi nộp.

## 1. Metadata (ẩn danh)

Nguyên tắc: không tên, không số điện thoại, không tên cơ sở nếu từ đó có thể đoán ra người. Ghi ở mức nhóm (ví dụ "bệnh viện tư lớn", "phòng khám nhỏ").

| Mục | Ghi |
|---|---|
| Mã người tham gia | P2 |
| Ngày phỏng vấn | |
| Hình thức (gặp trực tiếp / gọi thoại / video) | |
| Thời lượng | |
| Giới tính | |
| Nhóm tuổi (ví dụ 18-24, 25-34, 35-44, 45-54, 55+) | |
| Vai trò trong lần đi khám (tự khám / đi cùng người nhà) | |
| Loại cơ sở (bệnh viện công / tư, tuyến, lớn / nhỏ, phòng khám) | |
| Đi khám cách đây bao lâu (ngày) | |
| Đã đạt tiêu chí tuyển? (đi khám trong ~60 ngày và phải chờ) | Có / Không |
| Quan hệ với người phỏng vấn (không ghi tên; ví dụ "bạn của bạn") | |
| Người hỏi / người ghi chép | |

## 2. Xác nhận đồng ý

| Mục | Ghi |
|---|---|
| Đã đọc kịch bản xin đồng ý trong `interview-guide.md` | Có / Không |
| Đồng ý tham gia | Có / Không |
| Đồng ý cho ghi chú | Có / Không |
| Đồng ý cho ghi âm | Có / Không |
| Hình thức đồng ý (nói miệng / tin nhắn) và thời điểm | |
| Người tham gia biết có thể dừng bất kỳ lúc nào | Có |
| Có phần nào người tham gia yêu cầu bỏ? | |
| Ghi âm (nếu có) đã xóa sau khi chép lại, ngày | |

Xác nhận: không ghi tên, không chụp ảnh người hay giấy tờ y tế, không ghi nội dung về bệnh/chẩn đoán/kết quả khám. Nếu người kể lỡ nhắc, đã bỏ qua: Có / Không / Không xảy ra.

## 5. Bảng Event / Behavior / Workaround / Consequence

Mỗi dòng là một chuỗi nhân quả mà **chính người kể đã mô tả**. Nếu người đó không kể tới workaround hoặc hậu quả, ghi "không kể" chứ không điền suy đoán.

| # | Event (chuyện cụ thể đã xảy ra) | Behavior (họ làm gì) | Workaround (họ xoay xở thế nào) | Consequence (chuyện xảy ra sau đó) | Nguồn (mục 3/4) |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |

Ví dụ cách ghi (minh họa định dạng): Event: "đang ngồi chờ đến lượt vào phòng khám" / Behavior: (hành động họ kể) / Workaround: (cách xử lý họ kể) / Consequence: (kết quả họ kể).

## 6. Các tín hiệu cần để riêng

| Loại | Nội dung (nếu có) |
|---|---|

| Feature request người đó nêu (ghi nguyên văn, kèm: đã đào vào "để làm gì" chưa?) | |
| Điều không nhớ / không biết | |
| Nội dung ngoài phạm vi (sức khỏe) đã bỏ qua | |

## 7. Tự rà phỏng vấn

- Câu nào mình đã dẫn dắt hoặc hỏi tương lai? (ghi câu và đoạn trả lời đó, đánh dấu độ tin cậy thấp)
- Mình có nói về giải pháp của mình không?
- Chỗ nào mình nên hỏi tiếp mà bỏ lỡ?
- Chỗ nào người kể lảng đi?
